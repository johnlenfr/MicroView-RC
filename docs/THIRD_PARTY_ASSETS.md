# Third-Party Reference Assets and Sources

MicroView RC contains project-owned firmware and documentation plus a small number of reference visuals used to identify and document the SparkFun MicroView hardware.

## Reference image files

- `docs/images/microview_module.webp`
- `docs/images/microview_pinout.png`

These images are included as reference documentation assets and should be treated according to the applicable upstream/source terms rather than automatically under the MicroView RC MIT license.
